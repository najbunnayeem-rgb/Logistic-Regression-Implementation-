Logistic Regression Implementation
Project Overview
This project demonstrates the implementation of Logistic Regression, a supervised machine learning algorithm used for classification problems.
The project explores how Logistic Regression can be used to classify data and make predictions based on input features.
Objectives
* Understand Logistic Regression.
* Implement a classification model using Python.
* Train and evaluate the model.
* Explore One-vs-Rest (OVR) classification.
Technologies & Libraries Used
* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook
Project Files
* LogisticRegression.ipynb – Jupyter Notebook containing the implementation and experiments.
* simpleOVRcode.py – Python code demonstrating One-vs-Rest classification.
* requirements.txt – List of required Python libraries.
* .gitignore – Specifies files that Git should ignore.
Installation and Setup
1. Clone the repository
git clone https://github.com/najbunnayeem-rgb/Logistic-Regression-Implementation-.git
2. Navigate to the project directory
cd Logistic-Regression-Implementation-
3. Create a virtual environment
python3 -m venv .venv
4. Activate the virtual environment (Mac/Linux)
source .venv/bin/activate
5. Install the required libraries
pip install -r requirements.txt
6. Run the Jupyter Notebook
jupyter notebook
